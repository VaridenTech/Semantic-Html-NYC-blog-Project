# Semantic HTML — New York City Blog

โปรเจกต์ฝึก Semantic HTML: สร้างบล็อกหนึ่งหน้าเกี่ยวกับ New York City โดยไม่ใช้ `div`
ใช้ประกอบบทเรียนในคอร์ส **สร้างบล็อก New York City ด้วย Semantic HTML**

A one-page blog about New York City, built with semantic HTML only (no `div`).

## โครงสร้างโฟลเดอร์

| โฟลเดอร์ | คืออะไร |
|---|---|
| `start/` | จุดเริ่มต้น: `index.html` ว่าง ๆ ที่เชื่อม `style.css` ไว้แล้ว |
| `finish/` | ฉบับสมบูรณ์หลังทำครบ 17 ขั้นตอนของโปรเจกต์หลัก (บทเรียน 01–06) |
| `finish-extended/` | ฉบับหลังทำแบบฝึกหัดต่อยอดด้วยตัวเองครบ: `lang`/`title`/`alt`, Food Guide, ตาราง, ข้อความมีความหมาย, FAQ, footer (บทเรียน 07–10) |

ทุกโฟลเดอร์มี `index.html` และ `style.css` ที่เปิดในเบราว์เซอร์ได้ทันที
รูป วิดีโอ และเสียงโหลดจาก CDN จึงต้องต่ออินเทอร์เน็ต

## วิธีใช้

1. คัดลอกโฟลเดอร์ `start/` ไปเป็นโฟลเดอร์ทำงานของคุณ
2. ทำตามบทเรียน แล้วเปิด `index.html` ดูผลในเบราว์เซอร์
3. เมื่อทำเสร็จหรือติดปัญหา เทียบกับ `finish/` (หรือ `finish-extended/`)

## หมายเหตุ

`style.css` ไม่ต้องแก้ไข เป้าหมายของโปรเจกต์คือการเลือก HTML element ให้ตรงความหมาย
ไฟล์ `.mov` อาจเล่นใน `<audio>` ไม่ได้บนบางเบราว์เซอร์ (เช่น Firefox) ให้ลองเปิดด้วย Chrome หรือ Safari
